BAKA V2 / ORIGINAL PROVIDER

汽水音乐
Baka Provider

原创 Baka V2 provider，覆盖搜索、歌单与榜单、媒体解析、歌词、评论和链接。仅承诺 128k / 320k；VIP 使用酷我与网易云第三方整曲兜底，不交付试听。

https://gh.padao.fun/https://raw.githubusercontent.com/hebijunge/musicfree-plugins/master/baka-plugins/qishui.js
下载 qishui.js官方 Pages 备用

导入方式

  • Baka 客户端 → 插件管理
  • 导入 Provider → 在线链接或本地文件
  • 确认插件 ID 为 org.hebijunge.qishui

容器要求

  • 首行必须是 // @baka-provider 2
  • 同步 CommonJS 导出
  • 只使用官方 SDK，不含 Node API

五源合一
洛雪脚本

https://gh.padao.fun/https://raw.githubusercontent.com/hebijunge/musicfree-plugins/master/plugins/five-source-lx.plugin.v1.6.0.js
