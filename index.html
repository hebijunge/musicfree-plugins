澜音原生插件

音源与 MusicFree 目录同源，格式为 .ceru.js。手机版用 v2；桌面 2.5.0+ 可用 v3，两者 ID 相同，v3 会覆盖升级。

导入步骤

1

选版本
手机 v2，桌面 2.5.0+ 选 v3。

2

复制链接
在插件目录中切到「澜音 Ceru」，逐条复制。

3

本地导入
插件管理 → 添加插件 → 粘贴链接或选本地文件；首次启用授予 network 权限。
