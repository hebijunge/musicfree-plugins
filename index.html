BAKA V2 PROVIDER / V1.0.0

汽水音乐
Baka Provider

原创 Baka V2 provider，覆盖搜索、歌单/榜单、媒体解析、歌词、评论与链接。仅承诺 128k / 320k，VIP 走酷我与网易云第三方整曲兜底。

https://gh.padao.fun/https://raw.githubusercontent.com/hebijunge/musicfree-plugins/master/baka-plugins/qishui.js
查看清单

导入与能力

1

Baka 客户端
插件管理 → 导入 Provider → 粘贴在线链接或选择本地 qishui.js。

2

标准 V2 容器
首行 // @baka-provider 2，同步 CommonJS 导出，只使用官方 SDK。

3

已声明能力
搜索、实体、集合、发现、媒体、歌词、评论、链接解析与分享。

LX CUSTOM SOURCE / V1.6.0

五源合一
洛雪脚本

QQ、酷我、酷狗、网易云、咪咕。适用于支持洛雪 LX 协议的播放器，一次导入一个脚本。

https://gh.padao.fun/https://raw.githubusercontent.com/hebijunge/musicfree-plugins/master/plugins/five-source-lx.plugin.v1.6.0.js

导入步骤

1

洛雪 Music
设置 → 自定义源管理 → 导入 → 在线链接。

2

澜音 CeruMusic
插件管理 → 添加插件 → 粘贴链接，或选择本地 .js。

3

授予网络权限
首次启用时允许 network，之后在音源处切换即可。
